# РТС-Металл — прототип сайта

Проект ДАПИ (мини-команда, отдельно от Юнит). Клиент: РТС-Металл, ООО —
производство металлоконструкций, Пермский край. Текущий сайт: rtsmetall.ru
(Bitrix24-конструктор).

## Структура репозитория

- `/` — вариант **А** («Доверие вперёд»): цифры и факты сразу после hero, до
  продукта.
- `/v2/` — вариант **Г** («Форма всегда рядом»): сплит-hero с формой заявки
  видной без скролла + sticky-панель с телефоном на протяжении всей страницы.
- `styles.css` — общий стиль для обоих вариантов.

Оба — чёрно-белые прототипы структуры (не финальный визуальный дизайн).
Цвет, типографика и фото — следующий этап, после того как Босс выберет
направление и придут материалы от клиента.

## Черновик дизайн-системы (уже в CSS-токенах)

- Сетка — 8px, шкала отступов 8/16/24/32/40/56/80/120
- Вертикальный ритм между секциями — 120px десктоп / 60px мобила
- Контейнер — 1280px
- Радиусы — 4px контролы, 8px карточки, 0 full-bleed фото
- Hover — только цвет/рамка, без магнитных кнопок

## Что уточняется у клиента (см. полный бриф в артефакте карты сайта)

- Реальные фото цеха, команды, объектов (сейчас — плейсхолдеры)
- Сертификаты ГОСТ/ТУ, допуск СРО, аттестация сварщиков
- Детали портфолио: объект, объём, срок по каждому кейсу
- Какой e-mail для заявок актуальный (на текущем сайте расхождение
  zakaz@/info@ — в прототипе временно использован info@rtsmetall.ru)
- Третье направление («благоустройство») — подтвердить состав услуг
